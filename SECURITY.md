# Security and Responsible Disclosure

ELAS is a prompt and documentation project, not a software service that processes legal cases or stores user data.

## Sensitive information
Do not publish personal, confidential, privileged, or sensitive case materials in public issues or pull requests.

## Reporting concerns
For a concern involving exposed credentials, private information, or a repository security issue, do not post the sensitive details publicly. Contact the repository owner through an appropriate private GitHub channel.

## AI safety
Do not treat prompt instructions as a security boundary. Never provide secrets, credentials, or unnecessary personal data to an AI assistant.
