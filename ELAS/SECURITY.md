# Security Policy

## Scope

This repository contains prompts and documentation. It is not a hosted legal service and does not process user cases.

## Reporting

Do not publish personal data, confidential documents, credentials, or sensitive case details in a public issue.

For a security or privacy concern affecting this repository, contact the repository maintainer through the private contact method shown on the GitHub profile. Include:
- a concise description;
- affected file or workflow;
- steps to reproduce, if applicable;
- potential impact;
- a safe way to follow up.

Do not include live credentials or unnecessary personal information.

## Response

The maintainer will review reports as reasonably practicable. No response time or remediation outcome is guaranteed.
