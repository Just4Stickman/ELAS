# Versioning Policy

ELAS uses semantic versioning in the form `MAJOR.MINOR.PATCH`.

- MAJOR: incompatible changes to the prompt's structure, behavior, or licensing metadata.
- MINOR: new modules, workflows, or substantial backward-compatible capabilities.
- PATCH: corrections, clarifications, formatting fixes, and small improvements.

Every release should update `CHANGELOG.md`. Legal-source updates, if ever added, should identify jurisdiction, source, effective date, and verification date. Do not imply that a prompt release automatically updates the law.
