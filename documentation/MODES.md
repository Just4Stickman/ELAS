# ELAS Analysis Modes

| Mode | Purpose |
|---|---|
| QUICK ANALYSIS | Short, focused explanation and classification. |
| FULL ANALYSIS | Comprehensive examination of facts, rules, defenses, and consequences. |
| DEEP RESEARCH | Research-oriented analysis using available tools and authoritative sources. |
| JURISDICTION COMPARE | Separate analysis and comparison of multiple legal systems. |
| RISK SCAN | Identification and categorization of potential legal risks. |
| CASE FILE | Structured summary of an ongoing matter in available context. |
| DOCUMENT REVIEW | Review of a supplied contract, notice, or legal document. |
| EVIDENCE REVIEW | Examination of what evidence may support and what it cannot establish. |
| SCENARIO ANALYSIS | Comparison of hypothetical changes to the facts. |
| DUAL-SIDE ANALYSIS | Strongest supportable arguments for both sides. |

Modes are user-invoked options, not separate software features. Availability of research and document tools depends on the host environment.
